# Gauteweb Tap

Homebrew formulae by Gaute Holmin.

## AI Monitor for Claude

macOS menu bar app showing your Claude session and weekly usage limits (unofficial).
See [Gauteweb/aimonitor](https://github.com/Gauteweb/aimonitor) for details and limitations.

```sh
brew install gauteweb/tap/aimonitor
open "$(brew --prefix aimonitor)/AI Monitor for Claude.app"
```

## AI Monitor for Mistral Vibe

macOS menu bar app showing how much of your included Mistral Vibe usage you have used, and your API requests (unofficial).
See [Gauteweb/aimonitor](https://github.com/Gauteweb/aimonitor#ai-monitor-for-mistral-vibe) for details and limitations.

```sh
brew install gauteweb/tap/aimonitor-mistral-vibe
open "$(brew --prefix aimonitor-mistral-vibe)/AI Monitor for Mistral Vibe.app"
```
