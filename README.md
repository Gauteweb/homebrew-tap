# Gauteweb Tap

Homebrew formulae by Gaute Holmin.

## AI Monitor for Claude

macOS menu bar app showing your Claude session and weekly usage limits (unofficial).
See [Gauteweb/aimonitor](https://github.com/Gauteweb/aimonitor) for details and limitations.

```sh
brew install gauteweb/tap/aimonitor
open "$(brew --prefix aimonitor)/AI Monitor for Claude.app"
```
